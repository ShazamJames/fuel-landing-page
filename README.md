# FUEL Investment Group — Website

Landing site for FUEL Investment Group: passive real estate investing for pharmacists.

Static site — plain HTML/CSS/JS, no build step. Open `index.html` or serve the folder with any static server.

## Pages

- `index.html` — landing page
- `book.html` — schedule a call (embedded GHL calendar)
- `join.html` — investor club signup (embedded GHL form)
- `blog/` — blog index and articles

## Notes

- Booking calendar and signup form are GoHighLevel widgets; submissions and bookings land in GHL directly.
- `ghl-booking-custom.css` — optional stylesheet to paste into the GHL booking funnel page so it matches the site design.
- Photos are Unsplash placeholders — swap for brand photography when available.
